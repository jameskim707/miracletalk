라이라 아바타 그림 넣는 곳

- 파일 이름은 avatars.js 의 id 그대로 + .png  (예: doctor.png, chef.png)
- 정사각형, 256x256 이상 권장 (화면에서 둥근 모서리로 잘려 보임)
- 24개: doctor chef teacher developer firefighter police farmer astronaut
        artist singer scientist mechanic factory office judge pilot
        builder detective guitarist photographer athlete postman roboticist student
- 다 넣었으면 avatars.js 맨 위 USE_AVATAR_IMAGES 를 true 로 바꾸기
